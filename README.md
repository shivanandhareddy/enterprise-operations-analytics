# enterprise-operations-analytics
# Enterprise Operations & Supply Chain Analytics

## Project Overview
This project analyzes supply chain operations data to support business decision-making through SQL analysis, Python automation, PySpark processing, KPI reporting, and dashboard visualization.

## Business Problem
The objective is to identify operational trends, late delivery risks, category performance, and regional performance patterns to help business teams improve planning and performance tracking.

## Tools Used
- SQL
- Python
- Pandas
- PySpark
- Power BI
- GitHub

## Key Features
- Data cleansing and transformation
- KPI calculation
- Late delivery analysis
- Regional performance tracking
- Category performance analysis
- Shipping delay anomaly detection
- Executive dashboard reporting

## KPIs
- Total Sales
- Total Orders
- Total Profit
- Late Delivery Rate
- Average Shipping Days
- Sales by Region
- Profit by Category

## Project Structure
- data/: raw and cleaned datasets
- sql/: SQL KPI queries
- notebooks/: Python and PySpark notebooks
- dashboard/: Power BI dashboard
- screenshots/: dashboard screenshots

## Business Impact
This project demonstrates how data analytics can help identify operational bottlenecks, improve visibility into supply chain performance, and support data-driven planning decisions.
